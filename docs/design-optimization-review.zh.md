# 网页设计优化与逐项审查

## 1. 工作台字号

- 根因：新手引导、插件和云端任务有独立的 12–13px 字号，未沿用全站字号。
- 实现：这些页面的操作说明使用正文、辅助信息使用小号字；共用字号改用 rem，根字号保留浏览器偏好，正文仍为 16px、宽屏 17px。命令和密钥区域也同步放大。
- 影响链路：全站字号变量 → 工作台引导、插件配置、任务与文件列表；未改变接口、会员权限或计费。
- 审查：检查字号继承、移动覆盖样式、命令区域及弹窗底部按钮；移除了遗漏的 11–12px 等宽字体声明。
- 验证：106 个相关客户端交互测试、typecheck、lint、构建及 SEO 检查通过。本地浏览器加载真实构建和内存 API，在 390px 下检查引导与插件页；引导正文 16px，页面及弹窗无横向溢出，底部操作可滚动到达。
- 限制：工作台使用模拟账号与 API，未验证生产账号、实际模型调用或支付；本项尚未部署。
