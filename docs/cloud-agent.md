# 云端 Agent 部署说明

[返回 README](../README.md) · [用户使用指南](https://wechatai.app/docs/cloud-agent)

云端 Agent 是可选的 Plus 插件，默认关闭。运营方提供 AGT 执行环境；默认跟随对应微信链接当前选中的普通模型，进入插件后沿用上一次普通模型，需要固定模型时可在插件中单独指定。它不是 OpenClaw / Hermes 的云托管。当前支持文字、图片、可提取文字的 PDF、DOCX 和文本文件、微信已转写的语音，以及账号工作空间内的记忆与文件处理。可按要求生成 PDF 等文件，回传微信并提供任务页下载；不开放浏览器、人工审批或自主定时任务。

发送附件后，等暂存成功再用文字或带微信转写文本的语音说明要求；也可连续发送多个附件、混合图片和文档，或用 `@云 要求` 单次处理当前会话暂存的附件。一次最多 4 个附件、一批 8 MB、暂存 15 分钟。云端图片支持 JPG、PNG、WebP，受 AGT 限制单张最大 2 MB，需所用模型支持视觉；文档单个最大 5 MB，PDF 最多 100 页，扫描版需先做文字识别或改发相关页面图片。文件正文随要求发送给 AGT 并计入输入 token，组装后的任务文字最多 50,000 字符，还受云端上下文长度、模型输入和 credits 上限约束。解析或受理失败时不会创建任务、消耗执行次数或扣 credits；临时下载错误可重发要求。附件过大、正文过长或解析失败而需要换文件时，先发送 `/cancel` 清空，再发送处理后的附件和要求，避免继续追加到出错批次；受理成功后清空该批暂存附件。

模型输入计数优先使用原生接口；Chat Completions 或返回 404/405/501 的计数接口使用本地估算，每张图片预留 16,000 tokens，并保留文字、历史和工具信息的输入检查。图片估算不代表服务商的精确用量，实际上下文限制以模型服务为准；鉴权、限流和服务故障不会被当作“不支持计数”而跳过。

50,000 字符检查针对组装后的任务文字，包含文件名与附件包装。受理前还会按 AGT 序列化消息的实际长度检查不可省略的当前正文和系统提示词；AGT 在每轮调用前保护完整的当前输入，旧历史或工具结果挤占预算时，也不会裁掉当前要求及文件正文。完整输入放不下时返回明确的上下文限制错误，不生成或结算被截短正文的成功结果。该限制同时受云端固定上下文长度约束，提高用户模型输入上限不一定能解决。

受理成功后暂存附件已清空。任务随后失败、取消、被云端拒绝或要求补充信息时，提示会要求重新发送附件，等暂存成功后再发送完整要求；再次提交不会自动沿用失败任务的附件。下载或受理前校验失败仍保留暂存批次，按前述重试或 `/cancel` 指引处理。

任务受理时在账号存储中保存图片，重启后仍可恢复上传；上传使用 AGT 的账号隔离图片接口，任务只携带不可变图片引用，重试复用原图。上游任务确认受理、任务终止或会话清除后，微伴清理本地任务图片；AGT 图片和历史沿用远端保留策略，不会随本地清除自动删除。图片输入的计费与普通图片聊天一致，按文字输入和最终文字输出计 credits，不因图片输入另收按张费用；返回图片则每张另计 5 credits；图片识别的模型 API 费用以服务商账单为准。

## 配置与启用

非敏感参数放在相应环境的 Wrangler `vars` 中；生产环境由私有配置覆盖时，以实际部署配置为准。`AGT_APP_KEY`、`AGT_CALLBACK_KEYS` 使用 Cloudflare Secrets，本地可放在被忽略的 `.dev.vars` 中。不要把运营方 Key 发给浏览器或用户。

| 配置                           | 用途与默认值                                                                                                                                                                         |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `CLOUD_AGENT_ENABLED`          | 默认 `false`；`admin` 仅允许后台管理员内测，`true` 向所有 Plus 用户开放；均要求 AGT 配置完整                                                                                         |
| `AGT_ORIGIN`                   | AGT 服务的 HTTPS origin，无路径、查询或凭据；本地 loopback 允许 HTTP                                                                                                                 |
| `AGT_APP_ID`、`AGT_TENANT_ID`  | 运营方的应用与 tenant 标识                                                                                                                                                           |
| `AGT_APP_KEY`                  | 应用凭据，需有开通应用用户、管理受限工作空间及成员、配置 Agent 与工具、管理模型渠道（`models:manage`）、读写工作区文件（`workspace:read` / `workspace:write`）、执行和查询任务的权限 |
| `AGT_AGENT_ID`                 | profile 名称前缀，默认 `wechatai`，实际追加 `-v2`；小写字母开头，仅含小写字母、数字、`.`、`_`、`-`，前缀最多 61 字符                                                                 |
| `AGT_WORKSPACE_PREFIX`         | 默认 `wechatai`，模板按本地/生产区分；仅含英文字母、数字、`_`、`-`，最多 87 字符                                                                                                     |
| `CLOUD_AGENT_DAILY_LIMIT`      | 每账号每日受理次数，默认 30，范围 1–1000，小数向下取整                                                                                                                               |
| `CLOUD_AGENT_DEADLINE_MINUTES` | 默认 10 分钟，范围 1–30；到时请求停止，仍需上游确认                                                                                                                                  |
| `AGT_CALLBACK_KEY_VERSION`     | 新任务回调密钥版本，默认 `v1`，1–32 位英文字母、数字、`_`、`-`                                                                                                                       |
| `AGT_CALLBACK_KEYS`            | 版本到密钥的 JSON 对象，如 `{"v1":"<至少 32 字符的随机密钥>"}`；轮换见下文                                                                                                           |
| `PUBLIC_SITE_URL`              | 当前部署的公开 HTTPS 域名，用于生成 AGT 回调地址                                                                                                                                     |

数值限额会约束到上述范围；负数或非法值回退默认值。每账号最多 1 个活动任务，包含尚未确认上游是否受理的任务，不能通过重复发送绕过。

开关开启且配置完整后，插件页才允许 Plus 用户添加、启用云端 Agent。需先在微伴配置自己的文本模型。云端插件未单独指定时使用当前微信链接选中的普通模型，进入插件后沿用上一次普通模型；没有可用普通会话时才回退到第一个兼容的文本模型，也可为插件选择固定模型。模型需支持工具调用。配置显示可用仅代表本地检查通过，不代表 AGT 网络、权限或模型已联调成功；账号和工作空间在首次任务时按需开通。

首次测试可设为 `admin`，复用后台的 `admin_user` 身份及有效期。网页配置、微信入口与后台任务提交都检查同一账号权限；管理员仍须拥有 Plus 和正数 credits 余额。移除或过期的管理员权限不再允许新任务，未结束任务会请求停止；已有结果与账单继续保留。

## 文件处理与版本升级

本版依赖 AGT 的 `return_file` 工具和可用的隔离计算沙箱。先发布 AGT 对应改动，并重建、滚动更新实际使用的 VPS 或 Cloudflare 沙箱镜像；镜像新增 `python3-reportlab`、`python3-pil` 和 `fonts-wqy-zenhei`，中文字体位于 `/usr/share/fonts/truetype/wqy/wqy-zenhei.ttc`。沙箱节点须通过就绪检查，只有 Worker 健康不代表能生成 PDF。

微伴新任务使用 `-v2` profile，开放账号记忆、工作区读写、隔离计算和返回文件；保留旧 `-v1` profile 供原任务恢复，不原地修改旧策略。隔离计算只暂存声明的输入并回收声明的输出，不开放任意接收人发送或需要审批的外部写操作。

图片同时作为视觉输入和原始图片文件交给 AGT，可由隔离计算进行转 PDF、裁剪等处理。文档按提取的 UTF-8 正文保存到账号工作区，并随任务提供；PDF/DOCX 不保留原二进制或版式，适合正文分析与重新排版，不保证原样转换。隔离计算每次最多生成并返回 4 个文件，每个不超过 2 MiB、一批不超过 8 MiB；微伴接收端对已有工作区产物的硬上限为每个 16 MiB。AGT 对产物做内容快照，微伴校验大小、摘要，并解析 PDF 文档及各页内容，全部通过后保存到账号私有存储，再结算并投递。PDF、文本等非图片文件本身不另加 credits，平台按输入与最终回复文字计量；返回图片支持 PNG、JPEG、WebP、GIF 和 SVG，按实际内容识别，每张另计 5 credits，改文件名或以文件附件发送不改变计费。内部生成代码与工具消耗不另计。

文件可在任务页下载，保留 30 天；清空或删除所属会话会撤销下载。文件读取暂时失败时保留原任务重试，最多 10 分钟；文件不存在、读取被拒绝、超限、损坏或校验不符时明确失败且不扣 credits。等待文件接收时，可在任务页取消文件接收或发送 `/wx stop`；取消后本次不扣 credits，已发生的模型 API 费用以服务商账单为准。微信发送重试复用同一产物与消息标识，不重跑 Agent、不重复计费。

## 隔离、模型与回调密钥变更

每账号映射独立的应用用户与 restricted 工作空间，同账号云端会话可能共享记忆。应用、tenant 或服务地址改变后，旧映射不会自动迁移；不要直接用新的服务替换仍有任务的旧服务。

不再读取 `AGT_MODEL`。用户所选模型的渠道、协议、加密密钥、系统提示词与限额在接收任务时冻结；提交时同步至本账号专用的 AGT 模型渠道，每次明确指定该渠道与模型，不回退运营方默认模型。

输入上限约束每次模型请求的完整输入（包括系统提示词、历史及工具定义和结果）；Chat Completions 使用本地保守估算，Responses / Anthropic 优先使用原生计数，计数接口返回 404、405、501 时使用本地保守估算，可能提前达到上限。鉴权失败、限流及服务故障不会被当作缺少计数能力。输出上限按每次调用生效；credits 上限只约束平台结算，不限制服务商的 API 总费用。

每账号复用一个渠道；AGT 应用密钥必须包含 `models:manage`。已有密钥缺少该权限时，先为同一应用轮换包含完整所需权限的新密钥，并替换微伴 `AGT_APP_KEY`，再发布本版；本版还依赖 AGT 支持模型级 `maxInputTokens` 和缺失计数接口的本地估算，须先发布相邻 `agent-gpt` 项目的对应修复，再发布微伴，旧版 AGT 会拒绝新字段。当前 AGT 每应用最多 32 个渠道，扩大开放范围前需核对容量。已有云端配置未指定模型时自动使用当前微信的默认文本模型，无需补选；每个新任务在受理时固定实际模型与限额，之后默认模型变化不影响该任务。未记录用户模型的旧任务不会新提交。

更改模型只影响后续任务；重试复用原请求，已提交任务按原模型恢复。模型 API 密钥在微伴和 AGT 均加密存储，浏览器和任务查询接口不会返回明文密钥。

回调路径为 `/api/integrations/agt/callback/:token`，完整 URL 与每任务凭据由微伴自动生成，需要 AGT 可访问 `PUBLIC_SITE_URL`。回调仅唤醒任务对账，不能凭回调正文扣费；结果以服务端查询 AGT 后的权威终态为准，缺失回调时由轮询恢复。

未配置 `AGT_CALLBACK_KEYS` 时，仅 `v1` 使用既有 `ENCRYPTION_KEY` 派生每任务密钥。迁移到显式密钥环时，把原 `ENCRYPTION_KEY` 的同一个值保留为 `v1`，将新的随机密钥放入 `v2`，再将 `AGT_CALLBACK_KEY_VERSION` 切到 `v2`。所有旧任务及其回调处理完成前保留旧版本；显式密钥环不会为缺失版本回退，也不能用新随机值覆盖仍在使用的 `v1`。不要为轮换回调密钥而更换用于存储加密的 `ENCRYPTION_KEY`。

## 任务、费用与停用

微信通过 `/use 快捷名` 默认进入，或 `@快捷名 内容` 单次调用。添加、启用插件和扫码不改变默认 AI；网页可显式创建并选择云会话，本身不提交任务或扣费。实际任务在同一同步事务中校验 Plus、余额、并发、当日次数，并写入任务与宿主消息；重复源消息复用原任务。

新任务的列表、详情和会话记录展示用户要求、文件名和图片数量。完整附件正文仍保留在执行输入与模型历史中，供云端处理、后续追问和上下文摘要使用。在普通会话用 `@云` 单次处理文档后，后续普通模型仍可使用历史中的正文，并受该模型的上下文上限与摘要策略约束。云端任务仍按冻结的任务输入计费；后续普通模型调用按实际带入的上下文计费。旧任务沿用原先保存的内容。

接收任务时先预占一次当日次数；确定未提交或被上游明确拒绝提交时，任务进入 `rejected` 并释放预占次数。上游已受理后的失败或取消仍计次；请求停止本身不会立即释放次数，提交结果不明时继续保留预占，直到确认原任务。提交前校验被拒绝的消息不占次数。

模型 API 费用由用户在所选服务商处结算，包括 Agent 内部多次调用的费用；用户另按平台输入与最终输出结算 credits，不计内部模型与工具消耗，不预扣，成功后可能形成负余额。空结果、部分结果、澄清、失败或已确认取消不收成功账单。停止与完成并发时，先完成的有效结果仍可结算。详见[计费说明](billing.md#云端-agent)。

模型失败时，任务页与微信回复提供相同的处理建议：验证失败检查 API Key，访问被拒检查模型权限和服务商限制，计费或额度错误检查服务商余额、套餐或额度，模型或地址不可用核对服务地址、协议和模型 ID，限流或服务故障按提示稍后重试。错误分类不包含上游报错原文。失败不扣微伴 credits，已发生的模型 API 费用仍以服务商账单为准。

`/wx stop` 和任务页「停止」只登记停止意图，恢复运行器负责查询并请求上游停止。新建、切换会话保留旧任务执行，离开原会话后可去任务页查结果；重置、归档、清空、删除、停用插件或解绑微信会请求停止相关任务并作废自动投递资格。

`CLOUD_AGENT_ENABLED` 是新任务提交开关，关闭后按任务进度处理：

- 确定尚未提交的任务会结束为 `rejected`，不扣 credits，并释放预占次数。
- 已尝试提交、但尚未确认上游任务号的任务会保留停止意图，只读对账找到原任务后请求停止，不重新提交。
- 已关联上游任务号的任务继续查询、执行和结算，不会仅因关闭开关而自动取消。若要停止，用户可在任务页对本人任务点击「停止」，或在原会话发送 `/wx stop`；运营方需停下运行中任务时，还须在 AGT 侧检查并请求取消。

请求停止后，仍需等待上游权威终态；先完成的有效结果仍可计费，开关不能作为立即停止成本的保证。恢复期间保留有效的 `AGT_ORIGIN`、应用、tenant、`AGT_APP_KEY`、旧 profile 与回调密钥；删除凭据会阻断查询和停止。Plus 到期会为活动任务登记停止意图，与关闭新提交开关的行为不同；两种情况下，用户仍能查看本人保留的任务并请求停止。

微信上下文失效会暂存待发结果，不重新执行任务或重复扣费。页面提示等待接收时，可让用户向原微信发送 `/wx status` 恢复投递；普通文字可能另建任务。

## 数据保留与上线验收

清空或删除会话会清除相关任务在微伴保存的输入、结果、冻结请求与结果快照，隐藏任务并清理待发正文；账单与已结算金额保留。重置或新建会话不会删除云端记忆。当前不自动同步删除 AGT 的历史、记忆、模型渠道凭据或微信副本，运营方应明确远端保留策略并处理用户数据请求。

本地测试不等于真实 AGT 与微信联调。对外开放前，使用运营方测试账号验证：

1. Plus 且已配置自己的文本模型时，添加云插件（默认使用当前微信的默认文本模型，也可单独指定）、扫码，按实际快捷名发送 `/use 快捷名` 后提交文字任务，在任务页看到终态与微信回复；新建会话不产生任务或费用。
2. 重复消息不重复执行或结算；输入超限、余额不足和每日次数用尽有明确提示；失败和确认取消不收成功账单。
3. 请求停止、切换/删除会话、上下文失效恢复，以及服务重启后，任务仍按保存状态恢复，旧结果不串入新会话。
4. Free、云服务关闭或配置缺失时不允许新建任务；历史查询与请求停止仍可用，不向客户端暴露上游身份和凭据。
5. 发送一份中文 TXT，紧接着要求转成 PDF，核对完整正文、中文渲染、微信文件及任务页下载；模拟文件下载或微信发送失败与服务重启，核对只创建一个任务、只结算一次；清空会话后下载应失效。
6. 关闭新提交开关后，分别验证未提交任务释放预占、提交待确认任务对账停止、已关联任务继续恢复；对后者显式请求停止并等待终态，核对执行次数与最终账单。

微伴不会替部署者自动开放生产开关。实际受理、回调、费用和数据保留应以当前部署配置及真实联调结果为准。
