# wechatai i18n T2：en 营销层与页头页脚

## 交付与基线

- 当前卡是一个原子任务：在 T1 骨架上完整发布英文首页和价格页的译文。共用页头、页脚、定价和 FAQ 都是两条 URL 的组成部分，应随译文一起评审、验收、回滚。撤回该 PR 即撤回两条英文入口及其索引信号，无状态迁移。交付一个 OPEN PR，禁止合并或部署。
- 风险：中等。主要是价格、额度、退款和续费文案失真，英文路由输出中文或死链，以及共享组件影响现有中文页面。
- PR 目标 `main`，开发分支 `feature/wechatai-i18n-t2-en-cwc`。评估时当前 HEAD 与本地 `origin/main` 都是 `f83537a`，含已合并的 T1 PR #12；开发前核对远端 `main`，对照验证须用与开发相同的基线。PR 负责人为本卡「开发中」接手的开发 agent，负责开 PR、附上验收证据和响应评审；GitHub CLI 当前凭据检查失败，开发阶段开 PR 前需验证可用的仓库授权。
- T1 是唯一现有上游，已完成。T7–T10 已依赖 T2，可分别使用 T2 合入后的 `main` 开独立 PR。共享冲突面是首页、价格页、页头页脚、营销子组件及共用词典接口：T2 先合入；后续若两张卡确实要编辑同一共享文件，后提交者以已合入先行卡的 `main` 为基线，仅对该文件建立必要的线性依赖。优先各用自己的语言目录与登记模块。不开新卡，不改现有依赖。

## 已批准范围

- 原始白名单：`src/client/public-pages.tsx`、`site-header.tsx`、`site-footer.tsx`、`landing-steps.tsx`、`landing-use-cases.tsx`、`src/shared/landing-faq.ts`、`src/client/pages/pricing-plans.tsx`、`pricing-page.tsx` 和新建 `src/shared/i18n/en/*`。在允许文件中保留一致的默认中文词典，通过现有 locale 上下文选词，沿用所有计费、身份和交互逻辑。使用自然英文，价格、币种、额度及条款以中文为准。
- `src/shared/i18n/load.ts` 会把每个直接匹配 `./*/*.ts` 的文件作为路由登记读取，且拒绝 `zh-CN` 登记目录。将 `en` 的路径登记与词典分开：只让首页、价格页登记模块匹配现有 glob，其余词典可放更深一层；中文词典放现有获准文件。无需改中央注册表。
- 用户已批准最小扩围：只允许改 `src/shared/seo-content/pricing.ts` 的价格页标题、简介、FAQ 与关联链接文案，`src/client/cost-estimator.tsx` 的估算器文案，`src/client/pages/seo-related.tsx` 的关联区文案，`src/shared/seo.ts` 的结构化数据文案，以及直接对应的回归测试。四个文件中的文案调整仅服务于 `/en` 和 `/en/pricing`。JSON-LD 只换文案，结构不变；同一份文案供正文与结构化数据复用。禁止复制组件或另建词典副本。价格、额度、退款、续费沿用现有来源，计费、身份和交互逻辑不变。
- 不做：翻译文档、其他 SEO 落地页、法务页、工作台，改 Go 后端、支付行为、公开文档索引、部署配置或增加依赖。已登记的目的地使用对应语言路由；未翻译目的地保留真实的无前缀链接，例如 `/terms`、`/wechat-muse`，不拼出未登记 URL。保留片段与查询参数。

## 验收与证据

1. `/en`、`/en/pricing` 预渲染和浏览器渲染均为 200，提供完整英文营销文案。检查正文、页头页脚、套餐状态、FAQ 展开态、估算器展开态、关联链接和 `alt`、`aria-label` 等可读属性。附原始 HTML 及渲染结果的汉字扫描（如 `rg -n '\p{Han}'`）与关键英文标记，区分正文、可访问文本和机器元数据；中文语言切换器的既有自称 `中文` 可单独列出，不能掩盖正文残留。页面专属 JSON-LD 文案与翻译后的可见内容一致，原有结构、标识和金额保持不变。
2. `/`、`/pricing` 原有中文文案、金额、权益、链接目的地及交互不变。使用同一基线对比可见正文、可读属性和原有元数据；资源指纹及新增的语言切换项、hreflang 是预期差异。核对人民币价格、赠送额度、微信连接及插件限制、模型费另付、续费与退款说明，无新承诺。必要的文案和内链在本卡一并验收。
3. `/` 与 `/en`、`/pricing` 与 `/en/pricing` 分别自指并互指，中英文 canonical 各指自身，`x-default` 指向各自中文原路径，`lang` 和 `og:locale` 沿用 T1 定义。sitemap 对照主线只增加 `/en` 和 `/en/pricing` 两条 URL，已上线的英文文档条目保持不变。以生产资产 404 规则的本地预览验证 `/en/wechat-ai`、`/en/docs/not-registered` 等未登记路径实际 HTTP 404。
4. `pnpm check` 包含全量校验及构建，另用现有 `pnpm test:browser` 跑相关浏览器回归。全量测试和构建串行，先查负载、正在运行的重活和 `MemAvailable`；有重活或可用内存低于 2 GiB 时等待。附检查结果、sitemap diff、页面证据及改动文件清单。
5. 本需求文档仅留仓库根 `internal-docs/`，不导入 `src/`，不复制到 `public/`，不登记文档内容或 `/api/docs`。构建后按文件路径和独有标题核对公开资产及 Worker bundle 没有收录，生产规则预览下该文档直链不可访问且 `/api/docs` 不返回本文。
6. 英文首页的小薇示例用 `@<shortcut>`，并说明须替换为已配置的微信快捷名；`Xiaowei` 是英文展示名，不是默认快捷名。示例不改变既有配置或命令解析。
7. 英文首页隐私说明保留中文「不主动」限定，标题与正文均不承诺在任何情况下都不查看聊天或附件。
8. 英文价格页面包屑的 `Home` 链接与 JSON-LD `BreadcrumbList` 第一项都指向已登记的英文首页 `/en`；中文首页链接与共享实体标识不变。
9. 中文页面组件从获准文件内的默认词典读取文案；对照主线渲染，首页首段在「处理。」与「DeepSeek」之间保留一个空格。
10. 英文文档上线后，首页与价格页正文中的文档链接按登记选择语言，保留查询参数与片段；未登记目的地仍使用原路径。浏览器点击回归覆盖入门教程（含片段）、计费 FAQ 和估算器。
